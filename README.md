# Solar-power-generation-analysis
Analyzed solar power generation data from two plants using Python, Pandas, Matplotlib, and Seaborn. Explored power generation trends, compared plant performance, and studied relationships between solar irradiation, module temperature, and DC power through data analysis and visualization.

## Project Overview
This project analyzes solar power generation data from two solar plants to understand power generation patterns and the relationship between solar irradiation, module temperature, and DC power.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Objectives
- Analyze solar power generation data.
- Compare power generation between Plant 1 and Plant 2.
- Explore the relationship between solar irradiation and DC power.
- Study the relationship between module temperature and DC power.
- Analyze daily average power generation trends.

## Data Cleaning and Preparation
- Loaded generation and weather sensor datasets.
- Checked missing values and duplicate records.
- Converted date-time columns into datetime format.
- Combined Plant 1 generation data with weather sensor data.

## Analysis and Visualizations
- Solar irradiation vs DC power.
- Module temperature vs DC power.
- Correlation heatmap.
- DC power generation over time.
- Daily average DC power generation.
- Comparison of Plant 1 and Plant 2.

## Key Findings
Plant 1 recorded a higher average and maximum DC power value than Plant 2 in the analyzed data. However, these values alone do not establish which plant is more efficient.
